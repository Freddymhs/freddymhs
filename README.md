Desarrollador en Arica, Chile. Backend en Node.js y TypeScript, Python cuando conviene. Diez años de repos acá adentro: empecé con un juego en GameMaker en 2016 y hoy escribo servidores MCP.

## Qué hay en este GitHub

**Herramientas que uso a diario.** Un [radar de empleo](https://www.fmarcos.dev) que lee tres portales y me manda solo lo nuevo. [Hooks de git](https://github.com/Freddymhs/fmarcosdev.git-hooks) publicados en npm. Un [teleprompter](https://github.com/Freddymhs/teleprompter) que sincroniza el celular con la presentación. [task-hub](https://github.com/fmarcos-labs/task-hub), [priorityBox](https://github.com/Freddymhs/priorityBox), [gastómetro](https://github.com/Freddymhs/gastometro), una [extensión para arreglar el sueño](https://github.com/fmarcos-labs/sleep-reset). Si algo me molesta dos veces, le hago una app.

**IA aplicada.** [hylian-mcp](https://github.com/fmarcos-labs/hylian-mcp), un servidor MCP para una biblioteca de Steam. [biblioteca-rag](https://github.com/Freddymhs/biblioteca-rag), un motor RAG self-hosted con citas (FastAPI, pgvector, Docling). Flujos de n8n versionados, transcriptores, pruebas con visión. Y el flujo de trabajo con agentes que uso para programar.

**Plantillas para arrancar sin ceremonia.** Next.js, NestJS, Express, FastAPI, Flutter clean-arch, Phaser, extensiones de Chrome, servidores MCP, un heartbeat en Go. Cada proyecto nuevo sale de una.

**Mi CV como código.** [fmarcos.dev](https://github.com/Freddymhs/fmarcosdev.app.web) nace de un `resume.json`: una API lo sirve, un pipeline genera el PDF con mi propio [tema ATS](https://github.com/Freddymhs/jsonresume-theme-dev-ats-es), Vercel publica.

**Cosas para otros.** Un helper de licitaciones para pymes, una app para practicar un examen laboral, un POS, un backend de convivencia escolar, widgets de Android para Todoist.

**De dónde vengo.** Los `chklist_*` de 2021 son mis apuntes de HTML, JavaScript y React. Antes: CodeIgniter, Rails, Android en Java, GameMaker. Están ahí porque son parte del camino.
