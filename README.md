## Backend / Fullstack Developer · Node.js · TypeScript · 5+ years

Based in Chile, working remote. I build backends and the tooling around them: REST APIs, microservices, CI pipelines, and the agent workflows that keep a team's process honest.

**Open to backend and fullstack roles** in Node.js / TypeScript (NestJS, Next.js, React). Python is my second track, currently in progress.

### Latest work

**SIIGSA, for the SAG (Chile's Agricultural and Livestock Service)** · Sep–Nov 2026 · backend
- Production microservices in **AdonisJS 6**, DDD, **SQL Server**, Redis and Consul, delivered through PRs under architecture review on **Azure DevOps**.
- Cleared the SonarQube backlog of two services (BFF: 71 issues to 6; solicitudes API: ~110) and wrote the git hooks that keep them from coming back.
- Ran an **AI-first workflow** with Claude Code: commands that read each ticket from Azure, build its Postman collection, audit the PR and distil what was learned into the team's docs.

Before that: backend and web scraping at **Depot Group** (NestJS, Puppeteer, WhatsApp Business API with an OpenAI assistant), a fullstack POS system at **JL LTDA** (GraphQL, PostgreSQL, Flutter), and three years of React / Next.js at **Klog**.
